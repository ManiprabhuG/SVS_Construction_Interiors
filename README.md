# SVS Constructions & Interiors

## Overview

Professional construction company website for **SVS Constructions & Interiors** developed using Next.js (App Router), React, TypeScript, and Tailwind CSS.

Established in Sivakasi, Virudhunagar district, SVS Constructions delivers premium residential house building, turnkey civil engineering works, labor contracts starting at ₹620/sq.ft, and custom interior design across Tamil Nadu.

## Features

- **Responsive Design**: Fully optimized for 320px, 375px, 768px, 1024px, and 1920px viewports.
- **Dynamic Language Switcher**: Single-click toggle between English (`EN`) and Tamil (`தமிழ்`).
- **Dark / Light Theme Engine**: Persistent theme state with local storage support and smooth mode transitions.
- **Floating Utilities**: Bottom-right floating controls for language and theme management.
- **Interactive Project Showcase**: Filterable masonry gallery with Lightbox zoom modal preview.
- **Validated Contact Form**: Built with `react-hook-form` for structural consultation requests.
- **Comprehensive SEO**: Technical SEO including `sitemap.xml`, `robots.txt`, OpenGraph, Twitter tags, and Schema.org JSON-LD (LocalBusiness, Organization, FAQ).
- **Vercel Ready**: Structured for zero-config production deployment on Vercel.

## Installation

```bash
npm install
```

## Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Deploy

```bash
vercel deploy
```

## Technologies

- **Framework**: Next.js 15 (App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Form Management**: React Hook Form
